# Access to MySQL Migration Script

## Overview

This project is a Python-based migration utility developed to automate the conversion of Microsoft Access databases to MySQL.

The tool was created in an internship/project environment and focuses on simplifying repetitive migration workflows, reducing manual database conversion work, and preserving database structure consistency during migration.

The project was primarily designed as a technical automation and data migration utility.

---

# Features

- Microsoft Access database migration
- Automated conversion to MySQL
- SQL generation and execution
- Configurable migration parameters
- Relational data structure handling
- Migration workflow automation
